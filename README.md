# iPAS AI 應用規劃師（中級）技術學習地圖

互動式學習地圖，把機器學習分成八層：數學基礎、資料、模型、學習、訓練、評估、部署、治理，共整理 316 項技術。每一項都有：

- 功能、用途，以及在 iPAS 學習指引與歷屆試題中的出處
- 詳細說明、公式與計算
- Python 範例：多數可以按「執行」直接在瀏覽器中跑（Pyodide），也可以一鍵複製
- 考試重點
- 部分技術附互動動畫
- 「五個迴圈」：訓練、調參與模型選擇、資料、上線維運（MLOps）、導入與治理
